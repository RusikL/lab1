Практическая работа №1

Каждый файл — отдельная программа на C.
Сборка всех программ в Linux (нужен установленный gcc):
sh build.sh
Запуск первой программы:
./build/pw01-1
Для остальных заданий замените номер.

В Windows с установленным gcc в PATH запустите build.cmd.
Пример запуска: build\pw01-1.exe
build — папка для готовых программ, которую создают скрипты.
Каждая программа запускается отдельно.

В задании 1.3 PC622 — пример имени компьютера. Узнайте настоящее имя командой hostname, замените PC622 и пересчитайте число в скобках. Табуляция считается одним символом; перенос строки не учитывается. Сейчас первая строка содержит 11 символов, вторая — 17.
В задании 1.6 тики считаются секундами по коэффициентам из условия.
В задании 1.10 выбран NODE_ID = 42, как в тестовом выводе.
